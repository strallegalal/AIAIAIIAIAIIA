Introdução ao JavaScript

O JavaScript é a linguagem que faz uma página reagir: um clique, um texto digitado, um carrinho que soma os valores. Ele roda dentro do navegador.

  • HTML é o esqueleto: o que existe na página.
  • CSS é a roupa: como a página parece.
  • JavaScript são os músculos: o que a página faz.

Atenção: Java e JavaScript são linguagens diferentes. Aqui estudamos o JavaScript. Abra o Console (tecla F12) para ver as mensagens que ele escreve com console.log().
